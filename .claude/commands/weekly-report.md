아래 전달된 일일 업무 일지 파일들의 "업무 현황" 테이블 항목만 확인하고, 주간보고를 작성해줘.

$ARGUMENTS

## 작성 규칙

1. 각 일지의 "업무 현황" 테이블에서 카테고리를 기준으로 항목을 분류한다.
2. 카테고리 매핑:
   - `redmine` → [일감]
   - `자동화테스트운영` → [자동화테스트 운영]
   - `자동화시스템개발` → [자동화시스템 개발]
   - `기타` → [기타]
3. 테이블 순서: [일감] → [자동화테스트 운영] → [자동화시스템 개발] → [기타]
4. 해당 카테고리에 항목이 없으면 해당 테이블은 생략한다.

## 각 테이블 형식

### [일감]

| 유형 | 일감명 | 목표일 | 작업 상태 | 담당 | 업무 세부 내용 등 |
|------|--------|--------|-----------|------|-------------------|

- "업무 내용" 컬럼에서 유형(신규/진행 등)과 일감명을 파싱한다.
- 목표일은 비워둔다.
- 작업 상태는 일지의 "상태" 컬럼 값을 사용한다.
- 담당은 비워둔다.
- "업무 세부 내용 등"은 일감명으로 내용 파악이 충분하면 비워두고, 추가 설명이 필요한 경우에만 작성한다.

### [자동화테스트 운영], [자동화시스템 개발], [기타]

| 업무 | 세부 내용 | 비고 |
|------|-----------|------|

- "업무 내용" 컬럼에서 콜론(:) 기준으로 앞부분을 "업무", 뒷부분을 "세부 내용"으로 분리한다.
- 콜론이 없으면 전체를 "업무"로, "세부 내용"은 비워둔다.
- "비고"에는 해당 항목의 날짜(MM-DD 형식)를 기입한다.
- 같은 업무명이 여러 날에 걸쳐 있어도 각각 별도 행으로 작성한다.

## 출력 형식

마크다운 테이블로 출력한다. 누락 항목 없이 모든 업무 현황 테이블의 행을 포함해야 한다.
