아래 전달된 일일 업무 일지 파일들의 "업무 현황" 테이블 항목만 확인하고, 주간보고를 작성해줘.

$ARGUMENTS

---

## 1. 카테고리 매핑

각 일지의 "업무 현황" 테이블에서 "카테고리" 컬럼을 기준으로 항목을 분류한다.

| 일지 카테고리 | 주간보고 카테고리 |
|-------------|-----------------|
| `redmine` | [일감] |
| `자동화테스트운영` | [자동화테스트 운영] |
| `자동화시스템개발` | [자동화시스템 개발] |
| `기타` | [기타] |

**테이블 순서**: [일감] → [자동화테스트 운영] → [자동화시스템 개발] → [기타]

해당 카테고리에 항목이 없으면 해당 테이블은 생략한다.

---

## 2. 테이블 형식

### [일감] 테이블

```
| 유형 | 일감명 | 목표일 | 작업 상태 | 담당 | 업무 세부 내용 등 |
```

**파싱 규칙:**
- **유형**: 항상 `버그요청`으로 고정한다.
- **일감명**: `#번호` 이후의 텍스트를 추출한다. (예: `#204268 [WK10.1][DC2.0][정책 > 웹/넷앱/HTTPS정책] 설명`)
- **목표일**: 비워둔다.
- **작업 상태**: "업무 내용" 컬럼 앞부분의 상태 키워드를 사용한다:
  - `신규` - 새로 등록된 일감
  - `피드백` - 피드백 진행 중
  - `배포준비중` - 배포 준비 단계
  - `시험대기` - 시험 대기 상태
- **담당**: 비워둔다.
- **업무 세부 내용 등**: 일감명으로 내용 파악이 충분하면 비워둔다.

**중복 처리**: 같은 일감번호가 여러 날에 걸쳐 있으면 최신 상태 기준으로 하나의 행만 작성한다.

---

### [자동화테스트 운영], [자동화시스템 개발], [기타] 테이블

```
| 업무 | 세부 내용 | 비고 |
```

**파싱 규칙:**
- **업무**: "업무 내용" 컬럼에서 콜론(`:`) 기준으로 앞부분을 추출한다. 콜론이 없으면 전체를 "업무"로 사용한다.
- **세부 내용**: 콜론(`:`) 기준으로 뒷부분을 추출한다. 콜론이 없으면 비워둔다.
- **비고**: 비워둔다. (날짜는 세부 내용에 포함)

**중복 처리 (동일 업무 통합)**:
- 같은 업무명이 여러 날에 걸쳐 있으면 **하나의 행으로 통합**한다.
- 각 세부 내용 앞에 글머리 기호(`•`)를 붙이고, `<br>`로 줄바꿈하여 하나의 셀에 모두 넣는다.
- 각 항목 끝에 날짜(MM-DD)를 괄호로 표시한다.

**예시**:
```
| 업무 | 세부 내용 | 비고 |
| Playwright Healer 개발 | • 개발 계획 문서 (PLAN.md) 작성 (01-30)<br>• 개발 계획 문서 (PLAN.md) 수정, 보완 (02-03)<br>• 개발 계획 문서 (PLAN.md) 수정 (cursor skill 기반으로 변경.) (02-04) |  |
```

## 3. 특별 처리: "webkeeper 기능기반 리스트 작성"

이 업무는 여러 날에 걸쳐 진행되므로 **하나의 통합 행**으로 작성한다.

### 설정값
- HTTP 정책 총 개수: **187개**

### 누적 개수 계산
1. 일지에서 `"webkeeper 기능기반 리스트 작성"` 또는 `"기능기반 리스트 작성"` 항목을 찾는다.
2. 괄호 안 숫자를 추출한다: 정규식 `\((\d+)개\)`
3. 주간 합계를 계산한다.
4. 백분율을 계산한다: `(누적개수 / 187) * 100`

### 출력 형식

```
| 업무 | 세부 내용 | 비고 |
| Webkeeper Playwright 자동화 | • 기능기반 리스트 자동화 대상 분류 및 수정 작업<br>- HTTP 정책 : X% (누적개수/187개)<br>- 관련 기능 : 기능1, 기능2, ... |  |
```

**HTML 테이블 형식으로만 출력한다.**

- **카테고리 제목** (대괄호 텍스트): `<h3>` 태그 사용 (큰 글씨)
- **테이블 헤더**: `font-size:small` 적용 (작은 글씨)

## 5. 최종 확인사항

1. **누락 금지**: 모든 업무 현황 테이블의 행을 포함해야 한다.
2. **중복 제거**: 같은 일감번호는 최신 상태 기준으로 하나만 표시한다.
3. **동일 업무 통합**: 같은 업무명은 하나의 행에 글머리 기호와 줄바꿈으로 통합한다.
4. **특별 처리**: "webkeeper 기능기반 리스트 작성"은 통합 행으로 작성하고 누적 개수와 백분율을 계산한다.
5. **HTML만 출력**: HTML 테이블 형식으로만 출력한다.
